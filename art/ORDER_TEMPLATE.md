# 아트 주문서 양식

파일명: `art/orders/ART-NNN.md` (NNN은 3자리 연번). 기획 방이 작성, 사용자가 GPT에 전달, 기획 방이 검수.
사용자가 GPT에 보낼 때는 **STYLE_GUIDE.md 6번 고정 프롬프트 + 이 주문서의 "GPT 전달용" 블록**만 복사하면 된다.

---

```markdown
# ART-NNN: (짧은 제목)

- 상태: 대기 | GPT 진행중 | 검수중 | 수정요청 | 완료
- 우선순위: 높음(개발 막힘) | 보통 | 낮음(장식)
- 작성일: 1년차 기준 아님, 실제 날짜 YYYY-MM-DD
- 필요 시점: (어느 기능 개발 전까지)

## 납품 사양
| 항목 | 값 |
|---|---|
| 파일명 | `icon_job_convenience.png` (소문자, 밑줄, 영문) |
| 크기 | 128 × 128 px |
| 배경 | 투명 PNG |
| 종류 | 아이콘 / 포트레이트 / 전신 / 배너 / 배경 / UI |

| 저장 위치 | `art/review/` → 검수 후 `assets/img/` |

## 용도
어느 화면 어디에 어떤 크기로 보이는지. (예: 알바 목록 화면, 각 항목 왼쪽 64px로 축소 표시)

## GPT 전달용
(이 블록을 고정 프롬프트 뒤에 그대로 붙여 넣는다)

대상: (한 문장. 예: 편의점 앞치마를 입은 20대 점원이 계산대 뒤에서 정면을 보고 서 있는 모습)

포즈·표정: (해당 시)
반드시 포함: (예: 파란 앞치마, 계산대)
반드시 제외: (예: 간판, 가격표, 배경 소품)
참고: (기존 에셋 파일명이 있으면. 예: `icon_job_cafe.png`와 같은 시점·크기감)

- [ ] 팔레트 범위 안

- [ ] 64px로 축소해도 무엇인지 식별 가능 (아이콘만)
```

## 운영 규칙

- 한 주문서 = 한 파일(변형 포함 최대 4개). 묶어서 주문하면 하나 틀렸을 때 전체 재작업이 된다.
- GPT가 두 번 수정해도 통과 못 하면 주문서를 쪼개거나 설명을 다시 쓴다. 세 번째부터는 설명 문제.
- 완료된 주문서는 지우지 않는다. 나중에 비슷한 에셋 주문할 때 "참고" 란에 쓴다.
- 처음 3장은 반드시 **같은 종류(아이콘 3개)** 로 주문해서 GPT가 시점·그림자를 일관되게 내는지 먼저 확인한다. 통과 후 다른 종류로.
