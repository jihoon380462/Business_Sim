# 아트 스타일 가이드

이 문서는 GPT(아트팀)에게 **매 주문마다 함께 전달**한다. 한 번 정하면 프로젝트 끝까지 바꾸지 않는다.
바꾸면 기존 에셋 전부 재작업이 된다.

## 1. 스타일

### 기준 이미지 (모든 주문에 첨부)
| 파일 | 역할 |
|---|---|
| `art/reference/REF-main-M.png` | **확정 메인 화면 (남주인공).** 그림체·UI·배경 톤의 기준 |
| `art/reference/REF-main-F.png` | **확정 메인 화면 (여주인공).** 위와 짝 |
| `art/reference/REF-style-source.jpg` | 그림체 출처. **인물·머리색·체형은 따라하지 않는다**, 선화·셰이딩·색감만 |
| `art/reference/REF-layout-02.png` | 레이아웃 원본(그림체는 폐기). UI 배치 확인용 |
| `art/reference/REF-main-01-dark-late-stage.png` | 후반 단계 다크 UI 후보 (V3 결정) |
| `art/reference/REF-main-09-isometric-shop.png` | 사업 탭 아이소메트릭 뷰 후보 (V2 결정) |

GPT에 보낼 때는 반드시 "이미지 A/B는 그림체·구도 기준, 이미지 C(style-source)는 그림체만, 인물 복제 금지"라고 역할을 적어 준다.

### 그림체
- **일본 애니메이션 일러스트 스타일.** 얇고 또렷한 선화(굵기 일정), 부드러운 셀 셰이딩 2~3단계, 파스텔 계열의 맑은 색.
- 피부는 밝고 매끈, 볼에 옅은 홍조. 머리카락은 결 단위, 윗부분에 밝은 광택 띠 하나. 눈은 크고 또렷, 홍채 하이라이트.
- **배경도 같은 애니 배경미술 톤.** 캐릭터보다 살짝 밝고 단순하게. 흐림(보케)·사실적 질감·사진풍 금지.
- 금지: 피부·옷의 사실적 광택, 림 라이트, 그라데이션 남발, 치비·SD, 픽셀아트.
- 카이로소프트 "느낌"은 그림체가 아니라 UI·주 단위 진행 연출로 낸다.
- **이미지 안에 글자·숫자를 그리지 않는다.** (레퍼런스 화면의 글자는 자리 표시용이었음. 실제 에셋은 글자 없이, 텍스트는 전부 UI가 렌더)
- 한국 현대 배경: 분식집, 편의점, 원룸, 사무실.

### 주인공 외형 (확정)
| | 남 | 여 |
|---|---|---|
| 머리 | 검은 단발, 살짝 흐트러진 앞머리 | 어깨 길이 밝은 갈색, 가르마 자연스럽게 |
| 눈 | 갈색 | 갈색 |
| 기본 의상 (0~2단계) | 흰 셔츠 소매 걷음 + 검은 슬랙스 | 동일 |
| 기본 포즈 | 주머니에 손, 살짝 미소 | 동일 |
- 두 주인공은 **항상 같은 구도·같은 배경·같은 조명**으로 짝 맞춰 주문한다.
- 단계 진급 시 의상 교체: 3단계 정장, 5단계 고급 정장 (V3에서 확정).

## 2. 해상도 기준

- 논리 해상도: **360 × 640** (세로). 에셋은 **2배(@2x)** 로 제작.
- 종류별 납품 크기 (px):

| 종류 | 크기 | 배경 | 용도 |
|---|---|---|---|
| 아이콘 | 128 × 128 | 투명 PNG | 메뉴, 알바, 주식 종목, 사업체 |
| 캐릭터 포트레이트 | 512 × 512 | 투명 PNG | 주인공, NPC, 직원 |
| 캐릭터 전신 | 512 × 1024 | 투명 PNG | 메인 화면 |
| 상단 배너 배경 | 720 × 480 | 불투명 PNG | 사업체·장소 장면 |
| 전체 배경 | 720 × 1280 | 불투명 PNG | 타이틀, 엔딩 |
| UI 조각 (버튼, 프레임) | 주문서에 명시 | 투명 PNG | 9-slice 가능하게 모서리 균일 |

## 3. 팔레트

- UI·아이콘은 아래 기준 (기준 이미지 02의 팔레트). 캐릭터·배경 일러스트는 팔레트 자유(단, 채도를 과하게 높이지 않음).

| 이름 | HEX | 용도 |
|---|---|---|
| 틸 | `#2A9D8F` | 기본 포인트: 선택된 탭·재생 버튼·주 진행 게이지·현재 상태 강조 |
| 그린 | `#2E9E6B` | 수입 금액 텍스트, 상승 |
| 레드 | `#D9534F` | 지출 금액 텍스트, 하락, 경고 |
| 앰버 | `#E9B44C` | 체력 게이지, 생활비·돈 아이콘, 주의 |
| 차콜 | `#22262E` | 본문 텍스트, 아이콘 기본색 |
| 오프화이트 | `#F6F5F2` | 카드 배경, 창 배경 |
| 라이트그레이 | `#E6E8EC` | 게이지 빈 칸, 구분선, 비활성 |
| 슬레이트 | `#6C7A89` | 보조 텍스트(날짜·주차) |

- 카드: 흰색, 모서리 둥글게(반지름 약 16px), 옅은 그림자. 피드 한 줄 = 카드 하나.
- 후반 단계(법인 이후) UI는 네이비 다크 테마로 전환 예정. 참고: `art/reference/REF-main-01-dark-late-stage.png`. 색 확정은 V3에서.
- 사업 탭의 가게 뷰는 아이소메트릭 검토 중. 참고: `art/reference/REF-main-09-isometric-shop.png`. V2에서 결정.

## 4. 캐릭터 규칙

- 비율: **6~7등신** 실제 성인 체형. 모든 캐릭터 동일 기준.
- 주인공은 성별 선택 가능 → 남/여 2종 필수, 같은 구도·같은 명암 방향으로 짝 맞춤.
- 표정 세트: 기본 / 미소 / 곤란 / 놀람 / 진지 (포트레이트 5종 1묶음)
- 연애 대상 캐릭터는 추가로 **호감도 단계별 표정 2종**(수줍음 / 애정) 포함 → 총 7종.
- 얼굴 방향: 정면 또는 살짝 좌측 15°. 통일. 포트레이트는 가슴 위 상반신.
- 노출·선정성 없음. 연애 연출은 표정·거리·배경으로.

## 5. 아이콘 규칙

- 정사각형 안에 **대상 하나만**, 여백 10%.
- 탭 아이콘은 단색 실루엣(차콜), 선택 시 틸 + 아래 밑줄. 메뉴·항목 아이콘은 연한 색 배경의 둥근 사각형 안에 넣는다(기준 이미지의 피드 아이콘 참고).
- 같은 분류 아이콘은 같은 시점(예: 사업체 건물은 전부 정면 약간 위).

## 6. GPT 고정 프롬프트

매 주문의 맨 앞에 그대로 붙인다. 기준 이미지 3장(REF-main-M, REF-main-F, REF-style-source)을 첨부한다. `[ ]` 부분만 주문서 내용으로 채운다.

```
이미지 3장을 첨부했어. 역할이 다르다.
- 이미지 A, B (게임 메인 화면 남/여): 그림체, 인물, 배경 톤, UI 팔레트의 기준. 이 그림체로 그린다.
- 이미지 C (분홍 머리 인물): 그림체 참고용. 인물·머리색·눈색·체형·옷은 절대 따라하지 않는다.

일본 애니메이션 일러스트 스타일. 얇고 또렷한 선화, 부드러운 셀 셰이딩 2~3단계, 파스텔 계열 맑은 색.
배경도 같은 애니 배경미술 톤, 흐림 처리 없음. 6~7등신 성인, 20대. 치비·SD 금지.
피부·옷의 사실적 광택 금지, 림 라이트 금지, 사진풍 금지. 노출·선정적 구도 금지.
이미지 안에 글자·숫자·로고를 넣지 않는다.
[배경: 투명 / 단색 오프화이트 / 장소 묘사]
[크기: W x H px]
[대상 설명: ...]
```

## 7. 금지

- 글자, 숫자, 로고, 실존 브랜드(세븐일레븐, 삼성 등) 흔적
- 사진풍, 3D 렌더, 과한 그라데이션, 질감 노이즈
- SD·치비·마스코트풍, 과장된 큰 눈
- 실존 인물·실존 캐릭터 닮은 얼굴
- 노출, 선정적 포즈
- 주문서에 없는 요소 추가 (배경 소품 등)
