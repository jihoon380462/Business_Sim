# 아트 스타일 가이드

이 문서는 GPT(아트팀)에게 **매 주문마다 함께 전달**한다. 한 번 정하면 프로젝트 끝까지 바꾸지 않는다.
바꾸면 기존 에셋 전부 재작업이 된다.

## 1. 스타일

- **세미 리얼 셀 셰이딩 일러스트** (애니메이션·비주얼 노벨 톤). 깔끔한 선화 + 2단계 명암. 그라데이션 최소.
  - 픽셀아트는 GPT가 격자를 못 맞춰 일관성이 깨지므로 제외. (카이로소프트 "느낌"은 UI와 주 단위 진행 연출로 낸다)
  - **아기자기·SD·치비 스타일 금지.** 연애 콘텐츠가 들어가므로 캐릭터는 성인 분위기로.
- 차분하고 세련된 톤. 주인공과 상대 캐릭터는 20대 성인.
- **이미지 안에 글자·숫자를 그리지 않는다.** (GPT가 글자를 깨뜨림. 텍스트는 전부 UI가 렌더)
- 한국 배경: 편의점, 원룸, 분식집, 사무실 등 한국 생활 공간이 자연스럽게 보이도록.

## 2. 해상도 기준

- 논리 해상도: **360 × 640** (세로). 에셋은 **2배(@2x)** 로 제작.
- 종류별 납품 크기 (px):

| 종류 | 크기 | 배경 | 용도 |
|---|---|---|---|
| 아이콘 | 128 × 128 | 투명 PNG | 메뉴, 알바, 주식 종목, 사업체 |
| 캐릭터 포트레이트 | 512 × 512 | 투명 PNG | 주인공, NPC, 직원 |
| 캐릭터 전신 | 512 × 1024 | 투명 PNG | 메인 화면 |
| 상단 배너 배경 | 720 × 480 | 불투명 PNG | 사업체·장소 장면 |
| 전체 배경 | 720 × 1280 | 불투명 PNG | 타이틀, 엔딩 |
| UI 조각 (버튼, 프레임) | 주문서에 명시 | 투명 PNG | 9-slice 가능하게 모서리 균일 |

## 3. 팔레트

- UI·아이콘·배경은 아래 7색 기준. 캐릭터 일러스트는 팔레트 자유(단, 채도를 과하게 높이지 않음).

| 이름 | HEX | 용도 |
|---|---|---|
| 틸 | `#2A9D8F` | 긍정, 수입, 성장 |
| 버건디 | `#C44536` | 경고, 손실, 지출 |
| 앰버 | `#E9B44C` | 돈, 강조 |
| 차콜 | `#22262E` | 외곽·그림자·텍스트 대비 |
| 오프화이트 | `#F4F1EA` | 배경, 여백 |
| 슬레이트 | `#6C7A89` | 보조 배경, 비활성 |
| 스틸블루 | `#4A6FA5` | 정보, 링크, 주식 |

## 4. 캐릭터 규칙

- 비율: **6~7등신** 실제 성인 체형. 모든 캐릭터 동일 기준.
- 주인공은 성별 선택 가능 → 남/여 2종 필수, 같은 구도·같은 명암 방향으로 짝 맞춤.
- 표정 세트: 기본 / 미소 / 곤란 / 놀람 / 진지 (포트레이트 5종 1묶음)
- 연애 대상 캐릭터는 추가로 **호감도 단계별 표정 2종**(수줍음 / 애정) 포함 → 총 7종.
- 얼굴 방향: 정면 또는 살짝 좌측 15°. 통일. 포트레이트는 가슴 위 상반신.
- 노출·선정성 없음. 연애 연출은 표정·거리·배경으로.

## 5. 아이콘 규칙

- 정사각형 안에 **대상 하나만**, 여백 10%.
- 아래쪽에 네이비 1단계 그림자(오프셋 우하단).
- 같은 분류 아이콘은 같은 시점(예: 사업체 건물은 전부 정면 약간 위).

## 6. GPT 고정 프롬프트

매 주문의 맨 앞에 그대로 붙인다. `[ ]` 부분만 주문서 내용으로 채운다.

```
Semi-realistic anime cel-shaded illustration, clean lineart, two-step shading, minimal gradients,
mature and refined tone, adult characters in their 20s with realistic 6-7 head proportions.
No chibi, no super-deformed, no cute mascot style. Korean modern-day setting.
Absolutely no text, letters, or numbers in the image. No nudity or suggestive content.
[배경: transparent background / solid cream background]
[크기: W x H px]
[대상 설명: ...]
```

## 7. 금지

- 글자, 숫자, 로고, 실존 브랜드(세븐일레븐, 삼성 등) 흔적
- 사진풍, 3D 렌더, 과한 그라데이션, 질감 노이즈
- SD·치비·마스코트풍, 과장된 큰 눈
- 실존 인물·실존 캐릭터 닮은 얼굴
- 노출, 선정적 포즈
- 주문서에 없는 요소 추가 (배경 소품 등)
