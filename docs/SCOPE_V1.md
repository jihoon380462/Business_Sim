# 1차 수직 슬라이스 범위 (V1)

목적: **"주 단위로 돈 굴리는 게 재밌는가"** 를 가장 싸게 확인한다.
V1에서 재미가 없으면 대기업 단계는 만들어도 재미없다. 그래서 대기업은 V1에 없다.

## 한 줄 목표
플레이어가 **알바와 주식으로 종잣돈을 모아 첫 가게를 열고, 가게가 흑자로 돌아서는 순간**까지. 플레이 시간 15~20분.

## 포함 (이것만 만든다)

### 시간
- 주 단위 턴. 1년 = 52주. 표기: `3년차 17주`
- "다음 주" 버튼 한 번 = 수입·지출 정산 → 주식 변동 → 이벤트 판정 → 결과 요약 팝업
- V1 종료 조건: 가게 개업 후 **4주 연속 흑자** 달성 시 "1차 목표 달성" 화면. 그 뒤로도 계속 플레이 가능.

### 돈
- 초기 자금 100만원
- 생활비: 매주 자동 차감 (초안 12만원)
- 잔액 0 미만 = 그 주 행동 불가(알바 강제). 파산 없음(V1에서는 벌칙만)
- 대출 1종: 한도 500만원, 주 이자 1%. **페이싱 핵심** — 이게 없으면 첫 가게까지 2~3년 걸려서 지루함

### 알바 (3종)
| 알바 | 주급 | 체력 소모 | 비고 |
|---|---|---|---|
| 편의점 | 20만 | 보통 | 기본 |
| 택배 상하차 | 35만 | 큼 | 체력 바닥나면 다음 주 못함 |
| 카페 | 25만 | 적음 | 랜덤 이벤트로 "손님 팁" 가끔 |
- 체력 0~100. 알바가 깎고, 쉬면 회복. 체력 수치는 V1에서 "선택에 고민을 주는 장치"로만 쓴다.

### 주식 (5종목)
- 종목당 주 변동 ±5~15% 랜덤 워크. 종목별 변동폭 다름(안정주 2종, 변동주 2종, 잡주 1종)
- 뉴스 이벤트 2~3개가 특정 종목을 ±30% 흔든다 (1~2주 전 "소문"으로 힌트)
- 거래 수수료 0.5%. 주당 매매 횟수 제한 없음
- **주식이 최적해가 되지 않게**: 잡주 상장폐지 이벤트 1개 포함. 몰빵 리스크를 체감하게.

### 사업체 (2단계만)
| 단계 | 개업비 | 주 매출(기대) | 주 고정비 | 비고 |
|---|---|---|---|---|
| 노점 (붕어빵·토스트) | 300만 | 40~60만 | 15만 | 계절 영향 (겨울 ↑) |
| 작은 가게 (분식집) | 2,500만 | 120~180만 | 70만 | 직원 1명 고용 가능 (주 30만, 매출 +25%) |
- 운영 선택 (매주 1개): 가격 ↑/↓, 재료 업그레이드, 홍보, 휴무(체력 회복)
- 평판 0~100: 매출 배율. 재료·홍보로 오르고, 가격 올리면 내림

### 이벤트 (총 8개)
- 생활 3: 병원비(-30만), 친구 결혼 축의금(-10만), 중고 거래 득템(+15만)
- 주식 3: 호재 소문, 악재 소문, 상장폐지
- 사업 2: 단골 생김(평판 +10), 위생 점검(재료 등급 낮으면 벌금)

### 저장
- 자동 저장(매 주 종료 시), 슬롯 1개. 이어하기 / 새로하기만.

### 화면 (5개)
1. 메인: 상단 자금·주차·체력 / 중앙 주인공 + 현재 상태 / 하단 "다음 주" 버튼
2. 알바
3. 주식
4. 사업 (개업 전엔 "준비중" 안내만)
5. 주간 결과 팝업

## 제외 (V2 이후)
- 대기업, 사업체 여러 개, 업종 확장, 프랜차이즈
- 연애·결혼 (정식 콘텐츠로 V2에 들어감 → GDD에서 설계. V1 데이터 구조에 `relationships` 자리만 비워둠)
- 부동산, 자격증·공부, 인맥
- 파산 엔딩, 멀티 엔딩
- 사운드, 애니메이션, 튜토리얼 (텍스트 한 줄 안내로 대체)
- 아트: 전부 **플레이스홀더**(회색 박스 + 이름). 아트 주문은 V1 재미 판정 후.
- 다국어, 클라우드 저장

## 재미 판정 기준 (V1 끝나고 스스로 체크)
- [ ] "한 주만 더" 하고 싶은 순간이 있었나
- [ ] 알바 / 주식 / 가게 중 둘 이상을 저울질하는 선택이 있었나
- [ ] 첫 가게 열 때 기분이 좋았나
- [ ] 생활비 차감이 압박으로 느껴졌나 (느껴지면 성공, 안 느껴지면 수치 ↑)
- [ ] 주식만 했을 때가 가게보다 명백히 유리했나 (유리하면 실패 → 주식 변동폭 손질)
- [ ] 15분 플레이가 지루했나

3개 이상 ✕면 V2 가기 전에 V1 수치부터 손본다.

## 수치는 전부 초안
위 금액·비율은 플레이해보고 바꾸는 값이다. `src/data/*.json`에만 있고 코드엔 없다.
목표 페이싱: 노점 개업 15~25주차, 분식집 개업 2년차 안.
