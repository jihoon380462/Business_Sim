# 1차 수직 슬라이스 범위 (V1)

목적: **"주 단위로 돈 굴리는 게 재밌는가"** 를 가장 싸게 확인한다.
V1에서 재미가 없으면 대기업 단계는 만들어도 재미없다. 그래서 대기업은 V1에 없다.

## 한 줄 목표
플레이어가 **알바와 주식으로 종잣돈을 모아 첫 가게를 열고, 가게가 흑자로 돌아서는 순간**까지. 플레이 시간 15~20분.

## 포함 (이것만 만든다)

### 시간 (실시간, 카이로소프트식)
- 시간은 **자동으로 흐른다.** 1주 = 1배속 기준 **4초** (초안, `config.json`). 1년 = 52주 ≈ 3.5분.
- 표기: `3년차 17주`. 상단 바에 주 진행 게이지(한 주가 차오르는 바).
- 속도 조절: 일시정지 / 1배속 / 2배속 버튼. 메인 화면 상단.
- **창이 열리면 자동 일시정지, 닫으면 자동 재개.** 알바·주식·사업·설정 등 어떤 메뉴든 창이 떠 있는 동안 시간은 멈춘다. 이벤트 팝업도 동일.
- 한 주가 끝날 때마다: 수입·지출 정산 → 주식 변동 → 이벤트 판정. 결과는 팝업이 아니라 **메인 화면 알림 피드**에 한 줄씩 쌓인다 (멈추지 않음). 돈이 크게 움직이면(±50만 이상) 숫자 강조.
- V1 종료 조건: 가게 개업 후 **4주 연속 흑자** 달성 시 자동 일시정지 + **결산 리포트 창**(일러스트·축하 연출 없음, 숫자만). 그 뒤로도 계속 플레이 가능.

### 행동 모델 (실시간이라 "주 행동 1개"가 아님)
- 플레이어는 **상태를 설정**하고, 시간이 흐르면 그 상태가 매주 반복 적용된다.
  - 현재 활동: 알바 A / 알바 B / 알바 C / 휴식 (하나 선택, 바꾸기 전까지 유지)
  - 사업 운영 방침: 가격·재료·홍보 수준 (설정값. 바꾸기 전까지 유지)
- 주식 매매, 대출, 개업은 창을 열어(=일시정지) 즉시 실행.
- 체력이 0이 되면 활동이 자동으로 "휴식"으로 바뀌고 알림. 플레이어가 다시 알바로 바꿔야 함.

### 돈
- 초기 자금 100만원
- 생활비: 매주 자동 차감 (15만원)
- 잔액 0 미만 = 활동이 "편의점 알바"로 강제 전환 + 알림. 파산 없음(V1에서는 벌칙만)
- 대출 1종: 한도 800만원, 주 이자 1%, 50만 단위. **노점 개업 후에만 가능**(시작부터 열리면 1주차 개업으로 페이싱이 깨짐). 창은 사업 창 하단 카드. **페이싱 핵심** — 이게 없으면 분식집까지 2년 넘게 걸림

### 알바 (3종)
| 알바 | 주급 | 체력 소모 | 비고 |
|---|---|---|---|
| 편의점 | 20만 | -15 | 시작용. V2에서 알바 경력 → 업종 보너스로 차별화 |
| 택배 상하차 | 45만 | -30 | 단기 고수입. 체력 관리 안 하면 자동 휴식 전환 |
| 카페 | 25만 | -10 | 안정형. 20% 확률 팁 3만 |
| 휴식 | 0 | +35 | |
- 체력 0~100. 알바가 매주 깎고, "휴식" 상태면 매주 회복. 체력 수치는 V1에서 "선택에 고민을 주는 장치"로만 쓴다.
- 실시간이므로 플레이어가 방치하면 체력이 바닥나서 자동 휴식 → 수입 끊김. 이게 "지켜봐야 하는 이유"가 된다.

### 주식 (5종목)
- 종목당 주 변동 ±5~15% 랜덤 워크. 종목별 변동폭 다름(안정주 2종, 변동주 2종, 잡주 1종)
- 뉴스 이벤트 2~3개가 특정 종목을 ±30% 흔든다 (1~2주 전 "소문"으로 힌트)
- 거래 수수료 0.5%. 매매 횟수 제한 없음. 주식 창이 열려 있는 동안은 시간이 멈추므로 가격은 창을 닫아야 움직인다.
- **주식이 최적해가 되지 않게**: 잡주 상장폐지 이벤트 1개 포함(20주 이후 매주 3%, 1회). 심사 통보 주에 가격 -40% 즉시 적용·매도 가능, 다음 주 0원·소멸. 몰빵 리스크를 체감하게.

### 사업체 (2단계만)
| 단계 | 개업비 | 주 매출(기대) | 주 고정비 | 비고 |
|---|---|---|---|---|
| 노점 (붕어빵·토스트) | 300만 | 50~75만 | 15만 | 계절 배율 봄 1.0 / 여름 0.8 / 가을 1.1 / 겨울 1.3 |
| 작은 가게 (분식집) | 1,800만 | 120~180만 | 70만 | 노점 보유 시 해금. 직원 1명 고용 가능 (주 30만, 매출 +25%). 확장 시 평판 유지, 재료 등급 1로 초기화 |
- 재료비 = 매출 × 등급별 비율 (1등급 20% / 2등급 25% / 3등급 30%). 업그레이드 비용: 노점 30만·60만, 분식집 150만·300만. 홍보 주 비용 노점 5만 / 분식집 15만.
- 매출 배율 = 0.6 + 0.8 × 평판/100 (평판 50 → 1.0배). 가격 낮음 0.85 / 보통 1.0 / 높음 1.2.
- 순이익 = 매출 − (재료비 + 인건비 + 고정비 + 홍보 + 대출이자). 흑자 판정도 이 순이익 기준.
- 운영 방침 (설정값, 바꾸기 전까지 유지): 가격(낮음/보통/높음), 재료 등급(1~3, 업그레이드는 1회 비용), 홍보(끔/켬, 켜면 매주 비용), 영업/휴무
- 평판 0~100: 매출 배율. 재료·홍보로 매주 조금씩 오르고, 가격 "높음"이면 매주 조금씩 내림

### 이벤트 (총 8개)
- 생활 3: 병원비(-30만), 친구 결혼 축의금(-10만), 중고 거래 득템(+15만)
- 주식 3: 호재 소문, 악재 소문, 상장폐지. 소문 팝업엔 종목만 보이고 방향은 숨김 → 10만원 내면 방향·시점 공개, 무시하면 배너에 "내용 불명". 1~2주 뒤 ±25~35%. 소문은 항상 사실
- 사업 2: 단골 생김(평판 +10), 위생 점검(재료 등급 낮으면 벌금)

### 이벤트 표시
- 통보형(돈만 오가는 것): 알림 피드에 한 줄. 멈추지 않음.
- 선택형(소문 듣고 살지 말지 등): 팝업 + 자동 일시정지. V1에서는 소문 2개만 선택형.

### 저장
- 자동 저장(매 주 종료 시 + 창 닫을 때), 슬롯 1개. 이어하기 / 새로하기만.
- 앱을 나갔다 들어오면 **일시정지 상태로** 시작 (방치 중 시간이 흐르지 않음).

### 화면 (5개)
1. 메인: 상단 자금·`N년차 M주`·주 진행 게이지·체력·계절 / 속도 버튼(⏸ ▶ ▶▶) / 중앙 주인공 + 현재 활동 표시 / 알림 피드 / 하단 탭
2. 활동 창: 알바 3종 + 휴식 중 선택 (열리면 일시정지)
3. 주식 창
4. 사업 창 (개업 전엔 개업 버튼만, 개업 후 운영 방침)
5. 이벤트 팝업 (선택형)
6. 결산 리포트 창 (V1 목표 달성 시): 제목 "첫 가게, 4주 연속 흑자" / 기간(개업 N년차 M주 ~ 현재) / 표: 매출 · 재료비 · 인건비 · 고정비 · 대출이자 · 순이익 (4주 합계, 주 평균) / 현재 자산·부채·순자산 / 주 흑자 추이 막대 4개 / "계속하기" 버튼. 같은 구조를 이후 분기·연간 결산에 재사용.

## 제외 (V2 이후)
- 대기업, 사업체 여러 개, 업종 확장, 프랜차이즈
- 연애·결혼 (정식 콘텐츠로 V2에 들어감 → GDD에서 설계. V1 데이터 구조에 `relationships` 자리만 비워둠)
- 부동산, 자격증·공부, 인맥
- 파산 엔딩, 멀티 엔딩
- 사운드, 애니메이션, 튜토리얼 (텍스트 한 줄 안내로 대체)
- 아트: 전부 **플레이스홀더**(회색 박스 + 이름). 아트 주문은 V1 재미 판정 후.
- 다국어, 클라우드 저장

## 재미 판정 기준 (V1 끝나고 스스로 체크)
- [ ] 시간이 흐르는 걸 지켜보고 싶은 순간이 있었나 (2배속을 쓰고 싶었다면 지루한 구간이 있다는 뜻 → 그 구간 기록)
- [ ] 알바 / 주식 / 가게 중 둘 이상을 저울질하는 선택이 있었나
- [ ] 창을 열고 닫는 일시정지가 거슬리지 않았나
- [ ] 첫 가게 열 때 기분이 좋았나
- [ ] 생활비 차감이 압박으로 느껴졌나 (느껴지면 성공, 안 느껴지면 수치 ↑)
- [ ] 주식만 했을 때가 가게보다 명백히 유리했나 (유리하면 실패 → 주식 변동폭 손질)
- [ ] 15분 플레이가 지루했나

3개 이상 ✕면 V2 가기 전에 V1 수치부터 손본다.

## 수치는 전부 초안
위 금액·비율은 플레이해보고 바꾸는 값이다. `src/data/*.json`에만 있고 코드엔 없다.
목표 페이싱: 노점 개업 15~25주차, 분식집 개업 55~70주차, V1 목표 달성 ≈ 1배속 5분. (초안 수치로 분식집 평균 88주가 나와 개업비·노점 매출·대출 한도·생활비 조정)
