# GDD — 사업 경영 시뮬레이션 (가칭)

> 이 문서는 전체 비전. 실제 개발 범위는 `SCOPE_V*.md`가 정한다. 여기 있는 수치는 전부 초안.

## 1. 한 줄 요약
막 스무 살이 된 주인공이 100만원으로 시작해, 알바와 주식으로 종잣돈을 모아 노점에서 대기업까지 키워 나가는 **실시간 주 단위 경영 인생 시뮬**(카이로소프트식). 세로 모바일.

## 2. 핵심 경험
- **"조금만 더 보자."** 시간이 흐르며 매주 정산이 피드에 쌓이고, 다음 주가 궁금해서 화면을 못 끈다.
- **선택의 저울.** 매주 체력·시간·돈을 어디에 쓸지(알바/주식/가게/사람) 고민이 있어야 한다.
- **성장의 실감.** 노점 → 가게 → 법인 → 대기업. 단계가 바뀌면 화면·용어·고민의 크기가 함께 바뀐다.
- **사람.** 돈만 쌓는 게임이 아니라, 옆에 누가 남았는지가 엔딩을 가른다.

## 3. 시간
- **실시간 자동 진행.** 1주가 몇 초(초안 4초)에 흐르고, 1년 = 52주. 표기 `N년차 M주`. 실제 연도 없음.
- 속도: 일시정지 / 1배속 / 2배속. (V3에서 3배속·단계별 기본 속도 검토)
- **창이 열리면 자동 일시정지, 닫으면 재개.** 메뉴·팝업·선택 이벤트 모두. 플레이어가 생각하는 동안 시간은 멈춘다.
- 계절: 13주씩 봄/여름/가을/겨울. 업종 매출·이벤트에 영향.
- 게임 기간: **30년차 말 강제 결산 엔딩**(주인공 50세). 그 전에 대기업 달성 시 조기 엔딩 가능. 1배속 기준 30년 ≈ 1시간 45분, 실제로는 창 열고 닫는 시간이 더해져 3~5시간 플레이 예상.
- 행동 모델: 플레이어는 **방침을 설정**하고(현재 활동, 사업 운영 방침, 위임 여부), 시간이 흐르면 매주 그 방침이 적용된다. 즉시 실행형(매매·개업·대출·만남)은 창을 열어 처리.
- 내부 구현은 `advanceWeek(state)` 한 번 = 1주. 실시간은 ui가 타이머로 이 함수를 반복 호출하는 것뿐이다. 그래서 core는 여전히 턴 기반으로 테스트할 수 있다.

## 4. 자원
| 자원 | 설명 |
|---|---|
| 자금 | 현금. 매주 생활비 차감. 음수 불가(대출로 메움) |
| 체력 | 0~100. 알바·과로로 소모, 휴식으로 회복. 0이면 강제 휴식 + 병원비 |
| 평판 | 사업체마다 0~100. 매출 배율 |
| 신용 | 0~100. 대출 한도·이자 결정. 연체·파산 시 하락 |
| 호감도 | 인물별 0~100 |

## 5. 성장 단계

| 단계 | 호칭 | 진입 조건(초안) | 핵심 고민 | 해금 |
|---|---|---|---|---|
| 0 | 알바생 | 시작 | 생활비, 체력 | 알바, 주식 |
| 1 | 노점상 | 300만 | 입지, 계절 | 노점 1개, 대출 |
| 2 | 사장 | 2,500만 | 직원, 평판 | 가게 1개, 직원 고용 |
| 3 | 법인 대표 | 가게 2개 + 순자산 2억 | 자금 조달, 관리자 | 법인 설립, 지점 확장, 은행 대출 확대 |
| 4 | 중견기업 | 순자산 50억 | 경쟁사, M&A | 업종 인수, 임원 채용 |
| 5 | 대기업 회장 | 순자산 1,000억 + 상장 | 리스크, 유산 | 상장(IPO), 엔딩 트리거 |

- 단계 올라가면 **주인공 전신 일러스트·메인 화면 배경이 교체**된다. (원룸 → 오피스텔 → 사무실 → 회장실)
- 아래 단계 콘텐츠는 사라지지 않고 "위임" 된다. 가게는 매니저에게 맡기면 매주 자동 정산.

## 6. 시스템

### 6.1 알바 (0~1단계 주력, 이후 선택)
- 5~6종. 주급·체력 소모·부가 효과(인맥, 요리 스킬 등) 다름.
- 특정 알바를 N주 하면 관련 업종 개업 시 평판 보너스. (카페 알바 → 카페 개업 유리)

### 6.2 주식
- 종목 10~15개. 섹터(식품/IT/건설/바이오/엔터) + 변동성 등급.
- 주가 = 섹터 추세 + 종목 랜덤워크 + 뉴스 이벤트. 소문(1~2주 전 힌트) → 뉴스(실현).
- 상장폐지, 유상증자, 배당 존재. 몰빵이 최적해가 되지 않도록 설계.
- 5단계에서 **본인 회사 상장** → 주식판에 내 회사가 뜬다.

### 6.3 사업
- 업종: 요식(노점/분식/카페/레스토랑), 유통(편의점/마트), IT(앱/쇼핑몰), 제조(공장), 부동산(3단계부터).
- 사업체 공통 속성: 매출 기대치, 고정비, 평판, 직원 수, 재료/품질 등급, 홍보도.
- 매주 운영 지시 1개: 가격, 품질, 홍보, 휴무, 확장.
- 직원: 능력·급여·사기. 사기 낮으면 퇴사. 3단계부터 매니저 두면 운영 지시 자동.
- 경쟁사(4단계~): 같은 업종 NPC 기업이 가격 경쟁·인재 빼가기.

### 6.4 연애·인간관계
- 대상 캐릭터 **4명**(성별 혼합, 주인공 성별과 무관하게 선택 가능). 각자 직업·성격·돈에 대한 가치관이 다르고, 사업 진행과 얽힌다.
  - 예: 같은 알바 동료 / 거래처 사장 / 은행원 / 경쟁사 직원 — 확정은 별도 기획서
- 만남: 알바·업종·이벤트에서 등장. "사람" 창에서 즉시 실행형 "만나기"(체력·돈 소모, 쿨타임 1주)로 호감도 상승. 또는 활동을 "데이트"로 설정해 매주 자동 만남.
- 호감도 단계: 지인(0) → 친구(30) → 호감(60) → 연인(80) → 결혼(100 + 조건).
- 단계마다 전용 이벤트 1~2개. 연인부터 **사업 효과**(인맥 대출, 직원 추천, 정보 등) 발생.
- 결혼: 배우자 효과 지속 + 생활비 변화 + 가족 이벤트. 바람·방치 시 호감도 하락 → 이혼 이벤트.
- **돈만 쫓으면 관계가 식는다.** 몇 주 연속 안 만나면 호감도 자연 감소. 이것이 엔딩 분기의 핵심.

### 6.5 이벤트
- 풀: 생활 / 주식 / 사업 / 관계 / 세계(불황·호황·전염병 등 전체 경제 흔드는 것).
- 단계별 가중치. 선택지 있는 이벤트(2~3지선다)와 통보형 혼재.
- 세계 이벤트는 5~10년에 1번 큰 것(불황) — 안전 자산·현금 비중의 의미.

### 6.6 경제 밸런스 원칙
- 각 단계 체류 목표: 0단계 15~25주, 1단계 ~1년, 2단계 2~3년, 3단계 5년, 4단계 8년, 5단계 나머지.
- 모든 수치는 `src/data/*.json`. 코드에 숫자 없음.

## 7. 엔딩
- 30년차 결산 또는 5단계 달성 시.
- 축: 순자산 등급(A~F) × 관계(독신/연인/결혼/이혼) × 평판(존경/보통/악덕).
- 예: "모든 걸 가진 회장, 옆에 아무도 없다" / "작은 가게, 가득 찬 식탁" / "존경받는 기업가".
- 엔딩 일러스트 + 30년 요약 타임라인(그래프) + 업적 목록.

## 8. 화면 구조 (세로, 하단 탭 5개)
```
[ 상단 바 ] 자금 · N년차 M주 · 주 진행 게이지 · 체력 · 계절
[ 속도 ]   ⏸  ▶  ▶▶
[ 메인 패널 ] 주인공 전신 + 현재 장소 배경 + 현재 활동 표시
[ 알림 피드 ] 매주 정산·이벤트가 한 줄씩 쌓임 (스크롤)
[ 하단 탭 ] 활동 | 주식 | 사업 | 사람 | 설정  → 탭을 누르면 창이 뜨고 시간 정지
```
- "활동" 탭은 단계별로 알바 → 일정(위임·휴식·회의)로 이름이 바뀐다.
- 선택형 이벤트는 팝업으로 끼어들며 자동 정지. 통보형은 피드에만.
