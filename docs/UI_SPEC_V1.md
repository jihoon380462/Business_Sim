# UI 명세 V1

레퍼런스: `art/reference/REF-main-M.png`(메인), `art/reference/screens/SCR-01~06`(창). **레이아웃·구성은 레퍼런스대로, 그림은 플레이스홀더.**
수치는 전부 `src/data/*.json`에서 온다. 여기 적힌 숫자는 예시.

## 0. 공통

### 화면 틀
- 논리 폭 360px. 세로는 화면 높이에 맞춤. 전체 배경 오프화이트 `#F6F5F2`.
- 위에서 아래로 고정 순서: **상단 바 → 속도 버튼 → 메인 패널(캐릭터+배경, 남는 높이 전부) → 알림 피드(3줄) → 하단 탭**.
- 폰트: 시스템 산세리프. 금액은 숫자 굵게.

### 색 (STYLE_GUIDE 팔레트)
틸 `#2A9D8F` 포인트 / 그린 `#2E9E6B` 수입 / 레드 `#D9534F` 지출 / 앰버 `#E9B44C` 체력·주의 / 차콜 `#22262E` 텍스트 / 라이트그레이 `#E6E8EC` 비활성·게이지 빈칸 / 슬레이트 `#6C7A89` 보조 텍스트

### 카드
흰색, 모서리 16px, 그림자 `0 2px 8px rgba(0,0,0,.06)`, 안쪽 여백 14px.

### 금액 표기
- 피드·목록: 만 단위 축약 `+20만`, `-12만`, `+1,520만`
- 상세·결산: 원 단위 `₩1,000,000`
- 수입 `+` 그린, 지출 `-` 레드, 0은 차콜

### 창(모달) 규칙
- 모든 탭·팝업은 하나의 **모달 매니저**로 연다. 열림 = 타이머 정지, 닫힘 = 재개(속도 버튼이 ⏸ 상태였다면 정지 유지).
- 창이 열리면 뒤 화면을 `rgba(0,0,0,.45)`로 덮는다. 상단 바·속도 버튼은 덮지 않고 그대로 보이되 속도 버튼은 ⏸ 활성 표시.
- 창은 폭 320px(좌우 20px 여백), 위치는 세로 중앙보다 살짝 위. 상단에 제목(굵게 20px) + 오른쪽 닫기 X.
- 창은 동시에 하나만. 창 위에 팝업(이벤트)은 가능.
- 어두운 배경 탭 = 닫기.

## 1. 상단 바
한 줄, 카드 3개 + 계절.
| 칸 | 내용 |
|---|---|
| 보유 자금 | 라벨 "보유 자금" 작게 / `₩1,000,000` 틸 굵게. 자금이 음수면 레드 |
| 주차 | 달력 아이콘 + `3년차 17주` / 아래 **주 진행 게이지**: 칸 10개, 한 주가 흐르며 왼쪽부터 틸로 채워짐. 주가 넘어가면 0으로 리셋 |
| 체력 | 번개 아이콘 + `72/100` / 아래 앰버 게이지. 30 이하면 레드로 변경 |
| 계절 | 아이콘 + 글자 1자(봄·여름·가을·겨울). 13주마다 변경 |

## 2. 속도 버튼
가로 3개 `⏸ / ▶ / 2x`, 선택된 것만 틸 배경·흰 글자. 기본값은 **⏸(일시정지)**. 앱 시작·재진입 시 항상 ⏸.

## 3. 메인 패널
- 배경 이미지(장소) + 캐릭터 이미지. V1은 둘 다 플레이스홀더(연한 회색 사각형 + "배경" / "주인공" 글자). 파일명은 `assets/placeholder/bg_street.png`, `char_main_m.png`, `char_main_f.png`.
- 오른쪽 위에 흰 알약 라벨: 아이콘 + `현재 활동: 편의점 알바`. 활동 바뀌면 즉시 갱신.
- 장소 배경은 V1에서 1종(분식집 앞) 고정.

## 4. 알림 피드
- 최근 3건만 표시, 최신이 위. 카드 1장 = 1건.
- 한 줄 구성: 아이콘(둥근 연한 배경) / 제목 + 축약 금액(`주급 +20만`) / 오른쪽에 주차(`3년차 17주`) + 원 단위 금액 색상 표시.
- 금액이 없는 알림(체력 0, 이벤트 통보)은 오른쪽 금액 자리를 비움.
- 피드 카드를 탭하면 전체 로그 창(단순 스크롤 리스트, 최근 50건). 별도 디자인 없음.

## 5. 하단 탭
5개 균등: 활동 · 주식 · 사업 · 사람 · 설정. 아이콘 + 글자. 선택 시 아이콘·글자 틸 + 아래 밑줄 2px.
- 탭은 **창을 여는 버튼**이다(페이지 전환 아님). 열린 창의 탭이 선택 상태.
- 사람 탭: V1에서는 창에 "준비 중" 한 줄.
- 설정 탭: 이어하기/새로하기, 주인공 성별 전환(V1은 이미지만 바뀜), 사운드 토글(비활성).

## 6. 활동 창 (SCR-01)
- 제목 "현재 활동 선택".
- 카드 4개 세로: 편의점 알바 / 택배 상하차 / 카페 알바 / 휴식. 각 카드: 왼쪽 아이콘(둥근 연한 배경 56px) / 이름 굵게 + `주급 20만`(틸) / 세로 구분선 / `체력 -15`(레드, 휴식은 `+30` 그린) / 오른쪽 라디오.
- 현재 활동 카드는 틸 테두리 2px + 체크 아이콘.
- 하단 "적용" 버튼(틸, 전폭). 선택 안 바뀌면 비활성.
- 체력이 해당 알바 소모량보다 적으면 그 카드 흐리게 + 라디오 비활성 + `체력 부족` 작은 글자.

## 7. 주식 창 (SCR-02)
- 제목 "주식" + 아이콘.
- 맨 위 **소문 배너**(연한 앰버 배경): 활성 소문이 있을 때만 표시. 없으면 영역 자체 없음.
- 평가액 카드: `내 평가액 ₩2,340,000 (+4.2%)` — 보유 주식 현재가 합계, 괄호는 매입가 대비. 보유 없으면 `₩0`.
- 종목 5줄: 이름 / 현재가 `₩12,500` / 등락률(전주 대비, 그린·레드) / 오른쪽에 최근 8주 미니 라인 차트(상승 그린·하락 레드 채움).
- 줄 탭 → 펼침: `수량 [-] 10 [+]` 스테퍼 + 매수(틸) / 매도(흰, 틸 테두리). 다른 줄 탭하면 이전 줄 접힘.
  - 매수 버튼: 자금 부족 시 비활성. 매도: 보유 0이면 비활성.
  - 펼친 줄에 `보유 N주 · 평균 ₩N` 한 줄 추가.
- 수수료 0.5%는 확인 없이 즉시 차감, 피드에 `매수 한빛식품 10주 -125,600` 기록.
- 상장폐지 종목은 줄 흐리게 + `상장폐지` 빨간 태그, 매매 불가.

## 8. 사업 창 — 개업 전 (SCR-03)
- 제목 "사업 시작하기".
- 카드 2개: 노점 / 분식집. 왼쪽 썸네일(플레이스홀더 96×96) / 이름 굵게 / `개업비 300만` / `예상 주매출 40~60만`.
- 선택 가능한 카드 틸 테두리 + 체크. 조건 미달 카드는 전체 흐리게 + 자물쇠(`분식집`은 V1에서 노점 보유 + 자금 2,500만 이상일 때 해금).
- 카드 아래 상태 줄: 자금 부족 시 `자금이 200만원 부족합니다`(레드). 충분하면 비움.
- "개업하기" 버튼: 충족 시 틸, 아니면 흐린 틸 비활성. 탭 → 확인 팝업(`300만원을 쓰고 노점을 엽니다. 계속?` 취소/개업) → 개업 시 자금 차감, 창이 운영 화면으로 바뀜, 피드 기록, 메인 패널 라벨에 `노점 운영 중` 추가.

## 9. 사업 창 — 운영 중 (SCR-04)
- 제목 `분식집 운영` (노점이면 `노점 운영`).
- 가게 이름: 입력란 + 연필. 탭하면 인라인 편집, 20자 제한. 기본값 `우리동네 분식`.
- 평판: `68/100` + 틸 게이지.
- 이번 주 숫자 3칸: `이번 주 매출 +152만`(그린) / `고정비 -70만`(레드) / `순익 +82만`(그린·굵게). 아직 정산 전 주면 지난주 값 표시 + 작은 글자 `지난주`.
- 운영 방침 (설정값, 즉시 반영, 바꾸기 전까지 유지):
  | 항목 | 컨트롤 | 효과 |
  |---|---|---|
  | 가격 | 세그먼트 낮음·보통·높음 | 매출 배율·평판 변화 |
  | 재료 등급 | 별 3개, 탭하면 업그레이드 확인 팝업(1회 비용) | 평판 상승 속도 |
  | 홍보 | 토글 | 켜면 매주 비용, 평판 상승 |
  | 영업 상태 | 세그먼트 영업·휴무 | 휴무면 매출 0, 고정비는 나감, 체력 회복 |
- 직원: `직원 N명` 제목. 분식집만. 없으면 `고용하기` 버튼(주 30만 안내 + 확인 팝업). 있으면 카드(아바타 플레이스홀더 / 이름 / `급여 30만`) + 해고 버튼(작게, 확인 팝업).
- 노점→분식집 업그레이드: 운영 화면 맨 아래 `분식집으로 확장 (2,500만)` 버튼, 조건 미달 시 비활성 + 부족 금액 표시.

## 10. 이벤트 팝업 — 선택형 (SCR-05)
- 메인 위에 작은 팝업(폭 320, 높이는 내용만큼). 자동 일시정지.
- 아이콘 + 제목(`소문`) / 본문 2~3줄 / 버튼: 첫 번째 틸(주 선택지), 두 번째 흰(무시·취소). 버튼 2~3개 세로.
- 선택 전까지 닫기 불가(X 없음). 선택하면 결과를 피드에 기록하고 팝업 닫힘, 재개.
- 통보형 이벤트는 팝업 없이 피드만.

## 11. 결산 리포트 창 (SCR-06)
- V1 목표 달성 시 자동으로 열림(일시정지). 이후 설정 창에서 `최근 결산 보기`로 다시 열 수 있음.
- 제목 `첫 가게, 4주 연속 흑자` / 부제 `개업 1년차 23주 ~ 1년차 26주`(슬레이트).
- 표 3열: 항목 / 4주 합계 / 주 평균. 행: 매출·재료비·인건비·고정비·대출이자·**순이익**(굵게, 위에 구분선 진하게). 수입 그린·지출 레드. 노점이면 인건비 행 생략.
- 자산 한 줄: `현금 ₩N · 부채 ₩N · 순자산 ₩N`(순자산 음수면 레드).
- `주별 순이익` 막대 4개, 값 라벨 위, 주차 라벨 아래. 양수 그린, 음수 레드(아래로).
- 하단 `계속하기`(틸, 전폭). 닫으면 재개. 이후 같은 창 구조를 분기·연간 결산에 재사용(V2).
