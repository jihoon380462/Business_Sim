## REQ-006 [기획→개발] 열림 — 구조 개정: 월 턴제 + 주인공 스탯 (V1 개정 2)
- 날짜: 2026-11-02
- 내용: 실시간 주 단위를 **월 턴제 + 스탯 5개 + 본업/여가 슬롯**으로 바꾼다. 현재 버전은 태그 `v1-realtime`으로 박제했다(이미 있으면 그대로, 없으면 현재 HEAD에 만들 것). 근거·전체 사양은 `docs/SCOPE_V1.md`(개정 2), 화면은 `docs/UI_SPEC_V1.md` **13절**, 단계표는 `docs/HANDOFF_V1.md` 4절. 아래는 구현 관점 요약.

  **1. core 변경**
  - `advanceWeek` → `advanceMonth(state)`. 1턴 = 1개월. `state.time = { year, month(1~12) }`. 계절 3개월 단위(3~5 봄, 6~8 여름, 9~11 가을, 12~2 겨울).
  - 신규 `core/stats.js`: `state.stats = { stamina, skill, management, speech, knowledge }` (0~100), `state.condition` (0~stamina). 배율 함수 `wageMult(stat) = 0.8 + 0.4*stat/100`, `skillRevenueMult = 0.85 + 0.3*skill/100`, `fixedCostMult = 1 - 0.15*management/100`, `loanRateMult = 1 - 0.4*speech/100`. 스탯 상승은 월 결산에서 활동별 `statGain` 적용, 90 이상은 절반(소수 누적 허용).
  - 활동: `state.activity = { main: id, leisure: id, studyTarget?: 'skill'|'management'|'knowledge' }`. 본업·여가 정의는 `jobs.json`에 `slot: "main"|"leisure"`로 구분. 본업 `operate`(가게 운영)·`delegate`(위임)는 조건부 노출.
