## REQ-003 [개발→기획] 닫힘 — 기획과 다르게/임의로 정한 것
- 날짜: 2026-11-02
- 내용: 아래는 문서에 없거나 모호해서 개발이 정한 것. 확정값 또는 수정 요청 바람.
  1. **대출은 노점 개업 후에만 가능**(`config.loan.requiresBusiness: true`). 이유: 한도 500만이 시작부터 열리면 1주차에 노점을 열 수 있어 "15~25주" 페이싱이 깨짐. 끄려면 값을 `false`로.
  2. **V1 종료 조건의 "가게" = 분식집**(`businesses.goalBusinessType: "snackbar"`). 노점 4주 흑자로는 10주 만에 끝나 15분 플레이가 안 됨. 노점도 포함하려면 값을 `null`로.
  3. **재료비** = 매출 × 등급별 비율(1등급 20%, 2등급 25%, 3등급 30%). SCOPE 표에는 재료비가 없고 결산 리포트에는 행이 있어서 추가함.
  4. **평판 → 매출 배율** = 0.6 + 0.8 × (평판/100). 평판 50이면 1.0배, 100이면 1.4배. 가격 낮음 0.85배/보통 1.0/높음 1.2배. 평판 주당 변화: 가격(낮음 +1, 높음 -2) + 재료(1등급 -1, 2등급 +1, 3등급 +2) + 홍보 +2.
  5. 재료 업그레이드 비용: 노점 2등급 30만/3등급 60만, 분식집 150만/300만. 홍보 주 비용: 노점 5만, 분식집 15만. 휴무 시 체력 +10.
  6. 노점 계절 배율: 봄 1.0 / 여름 0.8 / 가을 1.1 / 겨울 1.3. 분식집은 계절 무관.
  7. 노점→분식집 확장 시 **평판 유지, 재료 등급은 1로 초기화**, 가게 이름 유지.
  8. **소문 이벤트 설계**: 팝업에 종목 이름은 나오되 호재/악재 방향은 숨김. 10만원 내면 방향+시점 공개. 무시하면 주식 창 배너에 "관련 얘기가 돈다(내용 불명)"로만 표시. 1~2주 뒤 ±25~35% 적용. 소문은 항상 사실.
  9. **상장폐지**: 20주차 이후 매주 3% 확률로 잡주(별빛엔터)에 "상장폐지 심사 통보"(피드, 1주 예고) → 다음 주 가격 0, 보유분 소멸. 1회만.
  10. 사업 순이익(`net`)과 흑자 판정에 **대출 이자 포함**(결산 리포트 표와 일치시키기 위해). 사업 창 KPI 가운데 칸은 "고정비" 대신 **"비용"(재료+인건비+고정비+홍보+이자)**으로 표기 → 매출 - 비용 = 순익이 맞아떨어지게.
  11. 위생 점검 벌금: 노점 20만 / 분식집 50만 (재료 1등급일 때만).
  12. 이벤트 확률(주당): 병원비 3%, 축의금 4%, 득템 4%, 호재 소문 6%, 악재 소문 5%, 단골 6%, 위생 4%. 주당 최대 1건, 이벤트별 쿨타임 6~16주. 카페 팁 25% 확률 3만.
  13. **대출 UI 위치**: 5개 화면에 대출 창이 없어서 **사업 창 맨 아래 "대출" 카드**(50만 단위 빌리기/갚기)로 넣음.
  14. 잔액 음수 강제 전환은 **체력 0이 아닐 때만**(체력 0이면 휴식 우선, 회복 후 전환).
  15. 설정 창 "이어하기" = 마지막 자동 저장으로 되돌리기. 앱 시작 시 저장이 있으면 "이어하기/새로하기" 팝업.
